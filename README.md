# 마켓 나침반

코스피·코스닥 시장 브리핑의 첫 개발 버전입니다. 프레임워크나 패키지 설치 없이 `index.html`을 브라우저에서 열어 사용합니다.

## 구현

- 반응형 시장 비교와 출처가 있는 경제지표
- 기본·상승·하락 시나리오 전환
- 관심 산업별 펼침/접기
- 브라우저 저장 기반 주간 점검표 및 초기화
- 키보드 조작, 동적 결과 알림, 동작 축소 설정 지원

## 데이터 범위

2026-11-10 기준의 정적 분석입니다. 실시간 시세, 자동 데이터 수집, 로그인, 서버 저장은 구현하지 않았습니다. 기준금리의 기준일은 2026-10-22이며 수출 지표는 2026년 10월 자료입니다. 외부 글꼴에 접속할 수 없는 경우 시스템 글꼴을 사용합니다.

## 실행

`index.html`을 직접 열거나 정적 웹 서버로 이 디렉터리를 제공합니다. 저장 기능은 브라우저 정책에 따라 파일 직접 열기에서 제한될 수 있으며, 이 경우 화면 내 체크 기능은 유지됩니다.
